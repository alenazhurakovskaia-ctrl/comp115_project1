# comp115_project1
An interactive day and night city drawing created using Python Turtle graphics.
The city includes buildings, a school, a pharmacy, a shop, trees, a road, and a car.
The daytime scene includes clouds and birds, while the nighttime scene includes stars and the moon.
The program uses functions, loops, and random numbers to create the drawings.
To run the program, open city_drawing.py in Python and follow the instructions to choose day or night.
